# Fixture connector package

This explicitly fictitious package exercises every v1 entry-point group. It is a development fixture, not a service integration.

After installing the host checkout:

```bash
.venv/bin/pip install -e ./examples/plugins/fixture-connectors
.venv/bin/python -m jobtracker doctor --skip-network
```

Private plugins use the same local-path flow or a pinned Git URL. No PyPI host-package dependency is implied for v0.2.0.
