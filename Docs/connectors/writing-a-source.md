# Writing a source connector

## Config only

```toml
[sources.example_board]
kind = "jsonld"
listing_url = "https://careers.example.invalid/jobs"

[sources.example_board.role_lane]
include_terms = ["engineer", "developer"]
exclude_terms = ["intern"]
```

Supported generic kinds are `rss`, `jsonld`, `html`, `json_api`/`json-api`, `sitemap`, and `csv`.

```bash
.venv/bin/python -m jobtracker fetch-source example_board --dry-run
```

## In-tree

Implement `JobSource.discover(ctx)` and `health(ctx)` in `jobtracker/sources/services/`, then use `@register_source`. The host owns payload construction and validation.

## Plugin factory

```toml
[project.entry-points."jobtracker.sources"]
example = "private_source.plugin:build_source"
```

```python
from jobtracker.core.models import ConnectorBuildContext

def build_source(context: ConnectorBuildContext):
    return ExampleSource(slug=context.slug, options=dict(context.options))
```

Install from a local path or VCS URL after installing the host checkout. Test with `fetch-source`, not a provider-specific command generated by documentation.

Every candidate must preserve stable external ID/source URL traceability. Add deterministic fixtures, contract tests, doctor health behavior, and privacy-safe docs.
