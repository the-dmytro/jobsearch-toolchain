# Privacy model

The public repository is designed to contain no filled profile, generated config, credentials, reports, databases, or personal onboarding state. Public examples are explicitly fictitious and use reserved domains.

The safety check scans tracked content and staged additions for repository deny-list values, conflict markers, tracked private paths, user home paths, contact patterns, and secret-shaped material. It reduces accidental disclosure; it does not make published Git history disappear from forks or caches.

If personal data ever reaches a public ref, stop publication, preserve evidence privately, remove retained refs with explicit approval, rotate affected credentials, and contact the hosting provider when cached-object removal is required.
